# Create vs. Add

## Guidance

Use "create" when an action produces something new that didn't exist before. Use "add" when an action places an existing item into or onto something that already exists.

## Examples

**Do:**
> Create an RBAC role.

> Add the user to the administrator role.

> Add instances to the Config Sync Group.

**Don't:**
> Add an RBAC role.

> Create the user in the administrator role.

## Notes

A quick test: think of creating a playlist and adding songs to it. "Create" generates a new structure. "Add" augments a structure that already exists.

If "create" or "add" appears as a literal label in the product UI or API, match the label even if it conflicts with this distinction.
