# And/or

## Guidance

Don't use "and/or." Decide which meaning you intend and write it. "And/or" is ambiguous in English, and many languages have no equivalent construction to translate it into.

## Examples

**Do:**
> Enter a hostname or an IP address, or both.

> Select a pool member or a node.

**Don't:**
> Enter a hostname and/or an IP address.

> Select a pool member and/or a node.

## Notes

If both options can apply at the same time, say so directly: "X or Y, or both." If only one can apply, use plain "or."
