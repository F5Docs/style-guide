# Semicolons

## Guidance

Don't use semicolons. Write two separate sentences instead. A semicolon lets you build one long sentence out of two ideas that are easier to read apart.

## Examples

**Do:**
> Check the configuration syntax for errors. Then reload NGINX to
> apply the changes.

> You can't edit a system-generated certificate. Only an
> administrator can replace it.

**Don't:**
> Check the configuration syntax for errors; then reload NGINX to
> apply the changes.

> You can't edit a system-generated certificate; only an
> administrator can replace it.

## Notes

If you're using a semicolon to join two related independent clauses, split them into two sentences. If you're using one to separate items in a list that already contains commas, restructure the list as a vertical list instead. See [Lists](../formatting/lists.md).

Splitting a semicolon-joined sentence also helps keep each half under the sentence-length limit. See [Sentence length](../voice-and-tone/sentence-length.md).
